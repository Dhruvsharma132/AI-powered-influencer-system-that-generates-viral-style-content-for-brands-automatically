# 🔥 AI-Powered Influencer System

An AI-powered system that generates **viral-style influencer content for brands automatically** and converts it into audio—simulating real-world social media reels.

---

## 🎯 Overview

Brands today struggle to consistently create engaging, high-performing content.

This project solves that by enabling users to:
- Generate **short, viral influencer-style scripts**
- Customize tone and personality
- Convert scripts into **audio for reels / TikTok**
- Simulate engagement using **views & likes**

---

## 💡 Key Features

- 🧑‍🎤 AI-generated influencer-style content  
- 🎭 Tone control: *Mild, Medium, Savage*  
- 🧠 Personality modes: *Gen Z, Gym Bro, Luxury*  
- 🔊 Text-to-Speech audio generation  
- 📱 Reel-style preview interface  
- 📊 Simulated engagement metrics  
- ⬇️ Downloadable audio output

## 🧠 How It Works

1. User inputs:
   - Brand name  
   - Tagline  
   - Tone & influencer style  

2. System generates:
   - A short, engaging influencer-style script  
   - Simulated social engagement metrics  

3. Output:
   - Reel-style preview  
   - Audio narration  
   - Downloadable file
