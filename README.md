🚀 AI Influencer Reel Generator

An AI-powered tool that generates viral, influencer-style content for brands and converts it into audio—simulating how modern creators produce engaging social media reels.

🎯 Overview

Creating consistent, engaging social media content is a challenge for many brands. This project solves that by enabling users to:

Generate short, viral-style scripts
Simulate influencer tone and personality
Convert content into audio for reels/TikTok
Preview engagement with mock social metrics
💡 Key Features
🧑‍🎤 Influencer-style content generation
🎭 Multiple tones: Mild, Medium, Savage
🏋️ Personality modes: Gen Z, Gym Bro, Luxury Influencer
🔊 Text-to-Speech (TTS) audio generation
📱 Reel-style UI preview
📊 Simulated engagement metrics (views & likes)
⬇️ Downloadable audio output
